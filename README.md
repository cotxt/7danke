# 7단계 영단어 — 선택한 디자인 배포본

이 배포본은 사용자가 첨부한 `7danke Landing.html`을 기준으로 만들었습니다. 이전에 제안했던 다른 랜딩 디자인을 사용하지 않았습니다.

## 준비 완료 / 실제 배포 미실행

정적 웹 파일과 `7danke.com` 연결용 CNAME을 준비했습니다. GitHub 앱이 연결되지 않아 **저장소 업로드·Pages 활성화·DNS 변경·HTTPS 확인은 실행하지 않았습니다.** 원본 HTML 파일도 변경하지 않았습니다.

## 원본에서 유지한 내용

검정 바탕, 라임·라벤더·주황 카드, 7단계 로고, 학습 휴대폰 화면, 문구, 7회 복습 일정, 맵기 선택, 단어팩, 담당 선생님, 가격, FAQ와 푸터를 유지했습니다. 컴포넌트 기본값은 원본의 `trialDays=7`, `priceMonthly=19,900`, `teacherName=박한`, `spice=중간맛`을 사용합니다.

## 배포를 위해 정리한 부분

편집기용 번들·컴포넌트 의존성을 일반 HTML/CSS/JavaScript로 바꾸고, 미치환 변수를 실제 기본값으로 바꿨습니다. 원본의 맵기 선택 기능을 유지하고 키보드로도 선택할 수 있게 했습니다. 작은 화면에서는 기존 카드를 세로로 배치하도록 반응형 스타일을 추가했습니다.

원본의 로고 세 글자는 같은 모양의 SVG 경로로 바꿨습니다. 본문 Pretendard는 공식 CDN에서 불러오며, 글꼴 파일은 이 패키지에 포함하지 않았습니다. 인터넷에서 글꼴을 불러올 수 없으면 시스템 글꼴로 표시됩니다.

페이지 제목·한국어 언어 속성·검색 설명·공유 이미지·파비콘·사이트맵·robots.txt를 추가했습니다. 화면에 있던 로그인·가입·영상·수업·약관 버튼은 실제 연결 주소가 없어, 현재는 연결 준비 안내를 엽니다. 회원가입이나 결제가 완료된 것처럼 동작하지 않습니다.

## 실제 기능 주소 연결

`assets/config.js`의 각 항목에 실제 HTTPS 주소를 입력하면 해당 버튼에서 이동합니다. 아직 주소가 없으면 비워 둡니다. 이 설정 파일은 공개되므로 비밀번호, API 키, OAuth secret은 넣지 마세요. 로그인·결제·상담·화상수업·알림·학습 데이터 서버는 이 랜딩 배포본에 포함되어 있지 않습니다.

## 공개 전에 확인할 원문 문구

사용자 요청대로 원문의 수치와 문구를 임의로 고치지 않았습니다. 다만 `92%`, `9,500+`, 강사 경력·평점·수업 횟수, `평생 네 거야` 등의 성과 표현에는 검증 자료가 첨부되지 않았습니다. 가격·환불·수업 이월 조건·모집 여부도 실제 운영 조건과 대조해야 합니다. 이 파일을 배포할 준비가 된 것과 해당 주장이 검증된 것은 별개입니다.

## 열기 / 배포

`index.html`을 열거나 이 폴더를 정적 웹 서버로 제공하면 됩니다. npm 설치나 빌드는 필요 없습니다. 배포 절차와 DNS 값은 `DEPLOYMENT.md`에 있습니다. 공개할 파일은 `index.html`, `assets/`, `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`입니다.

## 검사 범위

로컬 Chromium에서 320~1440px 화면, 맵기 선택, 키보드 선택, 17개 버튼·링크의 준비 안내와 Escape 닫기, 미치환 변수 제거를 검사했습니다. 화면 검사용으로 원본 글꼴을 메모리에서만 사용했습니다. 원격 CDN 통신, 실제 GitHub 배포, DNS·TLS, Safari·Firefox, 실제 로그인·결제는 검사하지 않았습니다.
